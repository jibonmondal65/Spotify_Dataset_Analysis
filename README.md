🎵 Spotify Dataset Analysis

This is an Exploratory Data Analysis (EDA) Project on the Spotify dataset.

📊 Project Overview

This project focuses on analyzing the Spotify dataset to uncover patterns and insights related to song features, popularity trends, language-based differences, and evolving musical styles. The goal is to better understand what makes a song popular and how audio characteristics change over time.

🔍 Key Analyses & Insights

The analysis includes:

Dataset Overview — Understanding the structure, size, and missing values in the dataset.

Univariate Analysis — Distribution of individual song features such as danceability, energy, and valence.

Bivariate Analysis — Relationships between pairs of features like energy vs danceability.

Multivariate Analysis — Clusters and relationships across multiple features.

Time Series Analysis — Trends in song features and popularity over the years.

Language-wise Analysis — How danceability, energy, and valence vary by language.

Top Artists Analysis — Most prolific artists and their musical profiles.
